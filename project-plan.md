# План проекта: Интернет-магазин на Vue

## 1. Что делаем
Разрабатываем фронтенд интернет-магазина на Vue 3. Пользователь сможет смотреть товары, фильтровать их, добавлять в корзину и оформлять заказы. Все работает без перезагрузки страницы.

## 2. Зачем это нужно
Пользователю важно, чтобы сайт работал быстро и плавно. На обычных сайтах при добавлении товара в корзину страница перезагружается — это раздражает. Наше приложение будет реактивным: все изменения происходят мгновенно, без ожидания.

## 3. Технологии
- **Vue 3** (Composition API — современный подход к коду)
- **Pinia** — для хранения данных (корзина, товары)
- **Vue Router** — для переключения между страницами
- **Axios** — для запросов к серверу
- **JSON Server** — для имитации бэкенда (временная база данных)

## 4. Что будет в магазине

**Страницы:**
- Главная (приветствие, популярные товары)
- Каталог (список всех товаров)
- Карточка товара (подробно об одном товаре)
- Корзина (выбранные товары, итоговая сумма)

**Планируемые Функции:**
- Фильтрация товаров по категориям и цене
- Поиск по названию
- Добавление/удаление товаров из корзины
- Изменение количества товаров
- Сохранение корзины даже после закрытия браузера

## 5. Этапы работы (3 недели)

### Неделя 1: Начало
- Создать проект
- Настроить роутер (чтобы страницы переключались)
- Настроить Pinia (хранилище)
- Сверстать шапку и подвал сайта
- Подготовить JSON Server с тестовыми товарами

### Неделя 2: Каталог
- Вывести список товаров на страницу
- Сделать фильтрацию по категориям и цене
- Сделать страницу товара с подробным описанием
- Добавить кнопку "В корзину"

### Неделя 3: Корзина
- Реализовать логику корзины: добавление, удаление, изменение количества
- Настроить сохранение корзины в localStorage (чтобы данные не пропадали)
- Сделать страницу корзины с подсчетом итоговой суммы
- Добавить мини-корзину в шапку сайта

## 6. Результат
- Страницы переключаются без перезагрузки
- После обновления страницы корзина не пустеет
- Фильтры работают
- Сайт нормально выглядит на телефоне и компьютере
- Код понятный, логика отделена от верстки
